# UAV-DualCog Supplementary Website

This repository hosts the supplementary website for **UAV-DualCog**, currently under peer review.

- Anonymous website: https://anonymous.4open.science/w/UAV-DualCog
- GitHub Pages: https://lozumi.github.io/UAV-DualCog/
- Code: https://anonymous.4open.science/r/UAV-DualCog-Code

The website presents the benchmark design, construction pipeline, evaluation protocol, leaderboard, paired dual-cognition analysis, training details, a Sim-to-Real 3DGS image pilot, and usage instructions.
